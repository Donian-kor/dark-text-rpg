데이터: shop.json (부위별 그룹)

구조 안내
- 최상위는 부위 이름을 키로 가지는 객체입니다.
- 각 부위는 아이템 객체의 리스트를 가집니다.
- '소모품'은 부위가 없는 소비성/기타 아이템을 보관합니다.

아이템 객체 필드
- 이름 (이름): 문자열
- 가격 (가격): 정수
- 회복력 (회복력): (선택) 정수
- 공격력 (공격력): (선택) 정수
- 방어력 (방어력): (선택) 정수

예제 (shop_template.json 제공):
{
  "소모품": [
    { "이름": "포션", "가격": 20, "회복력": 50 }
  ],
  "무기": [
    { "이름": "철검", "가격": 50, "공격력": 10 }
  ]
}

운영 지침
- 아이템을 추가하려면 해당 부위 리스트에 아이템 객체를 추가합니다.
- 동일한 아이템 이름이 중복되지 않도록 주의하세요.
- 코드에서는 로드 시 내부적으로 평탄한 SHOP_ITEMS 목록도 생성하므로 기존 코드를 바로 사용 가능합니다.

추가 기능(옵션)
- CLI 툴: 항목 추가/검증/삭제를 자동화하는 스크립트(원하시면 제작 가능)
