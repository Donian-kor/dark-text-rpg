# ⚔️ Dark Text RPG

**Dark Text RPG**는 Python과 Tkinter를 사용하여 제작된 텍스트 기반의 방치형 RPG 게임입니다.  
직관적인 GUI 환경에서 캐릭터를 육성하고, 던전을 탐험하며, 장비를 강화하는 재미를 느낄 수 있습니다.

![Python](https://img.shields.io/badge/Python-3.x-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

## ✨ 주요 기능

- **캐릭터 생성**: 다양한 직업(전사, 마법사 등) 선택 및 주사위 굴리기를 통한 초기 스탯 설정
- **자동 전투 시스템**: 던전 입장 시 자동으로 진행되는 턴제 전투, 스킬 자동 발동
- **성장형 던전**: 클리어 횟수에 따라 난이도(초급/중급/상급/보스)와 보상이 증가
- **상점 & 인벤토리**: 장비 및 소모품 구매, 수량 선택 구매, 툴팁 정보 제공
- **장비 강화**: 골드를 소모하여 장비 강화 (+1, +2...), 실패 시 페널티 적용
- **데이터 커스터마이징**: JSON 파일을 통해 몬스터, 아이템, 스킬 밸런스 조정 가능

## 🛠️ 설치 및 실행

이 프로젝트는 Python 표준 라이브러리만 사용하므로 별도의 패키지 설치(`pip install`)가 필요 없습니다.

### 필수 요구 사항
- Python 3.x 이상

### 실행 방법

1. 저장소를 클론하거나 다운로드합니다.
2. `data` 폴더가 `TextRPG.pyw` 파일과 같은 위치에 있는지 확인합니다.
3. 아래 명령어로 게임을 실행합니다.

```bash
python TextRPG.pyw
```

## 📖 게임 가이드

### 1. 마을 (로비)
- **인벤토리**: 아이템 확인 및 장착/사용.
- **상점**: 장비와 물약 구매. (소모품은 대량 구매 가능)
- **장비**: 현재 장착 중인 아이템 확인 및 강화 시도.
- **퀘스트**: 퀘스트 수락 및 완료 보상 획득.
- **휴식**: HP 완전 회복.

### 2. 던전 탐험
- 좌측 목록에서 던전을 선택하고 **입장** 버튼을 누르면 자동 전투가 시작됩니다.
- **반복** 횟수를 설정하면 해당 횟수만큼 연속으로 던전을 돕니다.
- 전투 중 체력이 0이 되면 자동으로 마을로 귀환합니다.

## 📂 폴더 구조

```text
DarkTextRPG/
├── TextRPG.pyw          # 게임 실행 파일 (소스 코드)
├── README.md            # 프로젝트 설명서
└── data/                # 게임 데이터 폴더
    ├── config.json      # 게임 설정
    ├── dungeons.json    # 던전 정보
    ├── jobs.json        # 직업 정보
    ├── monsters.json    # 몬스터 정보
    ├── shop.json        # 상점 아이템 목록
    └── skills.json      # 스킬 정보
```
