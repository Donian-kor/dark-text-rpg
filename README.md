
data 폴더가 TextRPG.pyw 파일과 같은 위치에 있는지 확인합니다.
===========================
DarkTextRPG/
├── TextRPG.pyw          (실행 파일 대신 소스 코드 파일)
└── data/                (데이터 폴더 - 필수)
    ├── config.json
    ├── dungeons.json
    ├── jobs.json
    ├── monsters.json
    ├── shop.json
    └── skills.json
=================================
TextRPG.pyw 파일을 더블 클릭하거나 터미널에서 아래 명령어로 실행합니다.

python TextRPG.pyw
